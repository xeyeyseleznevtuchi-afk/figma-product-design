# Reference source registry (directory, not a guarantee of current access)

| Source | Lane | Best use | Retrieval / caution |
|---|---|---|---|
| https://refero.design/ | Visual | Real web screens, content and page patterns | Visual catalog; confirm availability |
| https://mobbin.com/ | UX | Product flows, states, navigation | Coverage and access vary |
| https://pageflows.com/ | UX | Flow recordings and real interaction patterns | Paid access may apply |
| https://land-book.com/ | Visual | Marketing sections and typography | Screenshots, not component contracts |
| https://www.siteinspire.com/ | Visual | Editorial web direction | Inspiration only |
| https://www.lapa.ninja/ | Visual | Landing section comparisons | Inspiration only |
| https://www.awwwards.com/ | Visual | Art direction, motion | Don't assume UX quality |
| https://component.gallery/ | Components | Compare anatomy across systems | Follow to original system documentation |
| https://ui.shadcn.com/docs/mcp | Component registry | Reusable code, registries, CLI/MCP discovery | Inspect actual registry/code before adoption |
| https://21st.dev/ | Component marketplace | UI blocks, visual/code candidates | Check actual MCP integration and access |
| https://storybook.js.org/ | Components | Stories, props, fixtures and behavior | Depends on public Storybook availability |
| https://www.figma.com/community | Components | Native community libraries and kits | Inspect masters, licenses and quality |
| https://www.untitledui.com/ | Components | Figma libraries, page patterns | Some assets are paid |
| https://www.radix-ui.com/ | Behavior | Headless primitives and interaction | Not a visual design source |
| https://react-spectrum.adobe.com/react-aria/ | Behavior | A11y and keyboard behavior | Runtime guidance, not Figma certification |
| https://carbondesignsystem.com/ | Enterprise | Design-system component documentation | Adapt, don't copy entire brand |
| https://atlassian.design/ | Enterprise | Patterns, status, complex workflows | Adapt to scope |
| https://cloudscape.design/ | Enterprise | Dense tools, tables, workflows | Adapt to scope |
| https://www.assistant-ui.com/ | AI | Chat threads, composer, tools | Only for conversational products |
| https://docs.copilotkit.ai/ | AI | Agent action and generative UI | Behavior needs runtime tests |
| https://elements.ai-sdk.dev/ | AI | AI response components | Check migration/maintenance status |
| https://pair.withgoogle.com/guidebook-v2/patterns | AI UX | Human-AI design decisions | Design guidance, not plug-and-play UI |
| https://www.microsoft.com/en-us/haxtoolkit/ai-guidelines/ | AI UX | Human-AI interaction heuristics | Not component library |

Search strategy: locate **exact patterns** by task and content constraints, not just brand or genre. Only use 3–8 genuinely relevant candidates per major screen, fewer for minor edits.
