# Evaluation suite for v2
Test A — new B2B SaaS without UI kit: require task IA, user-role map, state matrix, constrained visual direction, coherent tokens, 2-3 linked screens and native component instances. Reject generic marketing dashboard.
Test B — design system from scratch: create semantic token collections, 4-6 genuinely demanded components with appropriate properties, modes and documentation, sample constructed screen, inspect reuse.
Test C — existing system surgical edit: modify only picker variant, preserve original file assets; screenshot regression and IDs.
Test D — brand kit from real client site: source-extracted logo/colors/font, genuine applications, no invented palette/typography, separate page and visual QA.
Test E — adverse long-copy: 2x label lengths, 200%-style typography stress, zero and error results, narrow device; no clipping.
Test F — API failure/retry: unloaded font mid-build must not create duplicates; check partial canvas before retry.

Each test scored 0–2 on intent, provenance, UX completeness, hierarchy, editing structure, reuse, states, responsiveness, QA and truthfulness = 20. Passing threshold: >=16 and **no hard gate failures**. Record screenshots, affected IDs, issues and actual outcomes; scoring is a proposed local rubric, not a validated benchmark.
