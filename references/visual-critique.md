# Visual direction and art direction

Start with subject, user task, density, brand and reference evidence. Distinguish greenfield brand exploration from strict reproduction.

## Direction artifact
For greenfield design provide 2–3 meaningfully different options only if decision value is real. Each option specifies typographic personality, grid, density, contrast, color semantics, imagery, icon language and 2 representative screen crops. Choose one based on brief and usability, not a generic trend.

## Critique rubric (0–2, with evidence)
- Task clarity and information hierarchy.
- Brand specificity ('remove the logo' test).
- Typographic quality (actual font, size hierarchy, line lengths, clipping).
- Rhythm: spacing, grouping, balance and tension.
- Data readability and scan patterns.
- Restraint and relevance of ornament.
- Responsive behavior and edge cases.
- Accessible focus, contrast and touch targets (measure where feasible, not screenshot guess).

Any 0 => revise; no score is evidence without concrete screenshot/viewport and failure description. Never impose full-bleed imagery, flashy motion or cardless marketing conventions onto a data-heavy working app. Explicit brand user overrides win over stale legacy source variables.

## Prompt-to-pixels feedback
Build representative view -> screenshot -> annotate specific defects -> targeted edit -> screenshot again. Avoid rebuilding complete composition because of one local spacing issue. Record which screenshot and node IDs were evaluated.
