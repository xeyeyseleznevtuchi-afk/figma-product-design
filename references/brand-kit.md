# Brand kit — distinct from UI kit
Goal: extract and document brand identity from **authoritative** brand assets and approved visual work. Avoid inventing graphics or turning request into component architecture.

Required evidence audit: logo variants and actual vector masters; font family/weights/licenses (do not distribute proprietary font files); core/accent/support palettes (distinguish actual source variable from newest user-approved correction); logo safe area and min size only when source supports, otherwise label proposed; icon/illustration motifs and intended tone; real applications.

Suggested single Figma page: Cover; Logo masters/clearspace examples; Palette/semantic roles; Typography specimens; Graphic language (real motifs, not decorative placeholders); Imagery/icons; Actual brand applications drawn from approved source; Do/Don't; AI-use guidance. Better 5 excellent sections than 10 generic sections.

Separate source-approved vs proposal. No arbitrary black gradient cards, fabricated mockups or generic social graphics labeled official. For any unverified policy use 'requires brand approval'. Use actual source vectors and screenshot QA at readable scale; ensure no cropped text. Do not change original site page or variables unless explicitly requested.
